Message.cs — модель сообщения

Назначение

Общая модель данных сообщения, используется и клиентом, и сервером для обмена JSON.

Где используется

Клиент:

хранится в ObservableCollection<Message>
отправляется на сервер
принимается с сервера

Сервер:

принимается в /send
хранится в памяти
возвращается в /receive

Назначение
Сервис для сетевого взаимодействия клиента с сервером.

Отвечает только за:
отправку сообщений
получение сообщений

Методы
public static async void SendMessageAsync(string serverUrl, Message message)

Назначение

Отправляет сообщение на сервер через POST.

Как работает
Сериализует Message в JSON
Отправляет POST на /send

public static async Task<List<Message>> RecieveMessageAsync(string serverUrl)
Назначение
Получает новые сообщения с сервера.

Как работает
Делает GET /receive
Читает JSON как List<Message>
Возвращает пустой список при ошибке

Program.cs — сервер
Назначение

HTTP-сервер чата

POST /send
принимает Message
добавляет Id и Timestamp
сохраняет в памяти
возвращает массив сообщений

GET /receive
возвращает только новые сообщения
сервер сам отслеживает, что уже отдавал каждому клиенту

GET /connect
регистрирует пользователя как активного

GET /users
возвращает список активных пользователей

Хранилище
MessageStore
ConcurrentQueue<Message> — все сообщения
ConcurrentDictionary — пользователи и состояние доставки
